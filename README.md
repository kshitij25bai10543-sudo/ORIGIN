The main issue with forest rights seems to be that records are spread out everywhere so pending cases or odd rejection rates get missed pretty easily. I think this project called FRA Monitor tries to pull the data together into one map and dashboard so officials can check on claims without digging through files all over the place.

Some districts show normal progress while others look worse or like they need attention. The map lets you click different spots and see the numbers for each area. There is also an AI part that checks for claims sitting too long or land sizes not matching up but it does not call anything fraud. It just points out the odd parts so someone can look closer later on.

The dashboard gives totals for approved pending and rejected claims plus how long processing takes. In one example a district had a thousand claims with seven hundred done and two hundred still open. The system flagged several that waited over half a year and a few with area mismatches. The note came back in plain words saying most cases moved forward but a handful needed review.

They built it with simple rules first like checking if days exceed one hundred eighty or if claimed land differs from records by more than ten percent. Those flags then go to an AI for a readable note. Everything runs on mock data for now with node on the back end and leaflet for the map. You install the packages add an api key and open the html file to see it. It is only a prototype so some parts feel loose in how the anomalies connect to daily work but the map view does make the numbers easier to glance at.
